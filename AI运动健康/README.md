# AI Smart Fitness Coach - AI智能私教

基于AI视觉识别和数据分析的个人健康管理平台

## 项目概述

产品定位：通过"饮食监管 + 智能菜单定制 + 数据闭环分析"为用户提供专业的私教级健康指导服务。

商业模式：SaaS订阅制（年费/月费会员）

## 快速开始

### 环境要求
- Node.js >= 18
- PostgreSQL >= 14
- Redis >= 6
- Docker (可选)

### 后端启动
```bash
cd backend
npm install
npm run start:dev
```

### 前端启动
```bash
cd frontend
npm install
npm start
```

### 使用Docker
```bash
docker-compose up
```

### 代理与限流配置

后端通过 `TRUST_PROXY` 指定 Express 信任的代理，以客户端 IP 分别限流：

- 未设置、空值、`false` 或 `0`：不信任转发头，适合直接暴露后端。
- 非负整数（例如 `1`）：信任指定层数的代理。只适合所有外部请求都经过相同层数代理的拓扑。
- 逗号分隔的代理 IP 或 CIDR（例如 `127.0.0.1,::1/128`）：仅信任这些来源地址。

不要设置为 `true`；非法值会使启动失败。使用层数配置时，必须阻止外部请求直接访问后端，且入口代理必须覆盖客户端提交的转发头。

本仓库 Compose 使用一层 Nginx，设置 `TRUST_PROXY=1`，后端端口仅发布到 `127.0.0.1:3000`。Nginx 配置覆盖 `X-Forwarded-For`，只使用实际连接地址。如果绕过 Nginx 直接对外部署后端，请关闭 `TRUST_PROXY`；多层代理需按实际拓扑重新配置。示例 Nginx 仅提供 HTTP，HTTPS 需另行配置证书和监听端口。
